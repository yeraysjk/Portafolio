# Portafolio — Yeray Priede

Portafolio personal, construido con Next.js. Backend Developer enfocado en Python y FastAPI, en búsqueda de mi primera oportunidad como desarrollador backend.

🔗 **Demo:** _(añadir URL de Vercel aquí una vez desplegado)_

## Stack

- [Next.js](https://nextjs.org) 16 (App Router) + React 19 + TypeScript
- [Tailwind CSS](https://tailwindcss.com) 4
- [Framer Motion](https://www.framer.com/motion/) para animaciones

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Estructura

- `app/` — páginas y layout (App Router)
- `components/` — componentes de cada sección (Hero, Proyectos, Experiencia, Contacto...)
- `data/portfolioData.ts` — contenido del portafolio (perfil, proyectos, tecnologías, experiencia)
